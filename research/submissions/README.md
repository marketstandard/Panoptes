# Research submissions

Use one subdirectory per contribution, for example:

```text
research/submissions/kgw-controls-2026-08/
  dataset-manifest.json
  calibration-artifact.json
  benchmark-card.json
  watermark-eval-card.json
  repro.md
```

Do not commit raw non-redistributable text. Submit hashes, schemas, small synthetic fixtures, and reproducible commands. Maintainers review calibration bundles and detector registry changes before release.
