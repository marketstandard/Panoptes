# Reference baseline runs

This directory holds the project's own canonical baseline runs, promoted here by maintainers with:

```bash
python baselines/baseline.py promote --run baselines/runs/<model-slug>_<kind>
```

Unlike community submissions (which enter `baselines/catalog/` as hashes only), reference runs are committed in full — outputs and manifest — because they are generated by maintainers from the project's own original prompts and are used as the pinned comparison set for calibration research.

## Conventions

- Folder name: `<model-slug>_<kind>`, e.g. `gpt-5.6-sol_text`, `gpt-5.6-sol_code`.
- Slugs are lowercase: letters, digits, dots, dashes (`gpt-5.6-sol`, `claude-opus-5`).
- Each folder contains one `<prompt-id>.md` per prompt, `run.manifest.json`, and optionally `run.manifest.json.ots`.
- The manifest's `interface` field records how the run was produced (`api`, `chat-ui`, or `agent-chat`). Agent-assisted runs are a distinct cohort and must never be blended with `api`/`chat-ui` runs in analysis.
- A run is promoted only after `finalize` and, for release use, `anchor`.
