# Code of conduct

Panoptes contributors are expected to be respectful, precise, and open to correction.

Do not:

- harass or discriminate against contributors or users;
- present probabilistic output as certainty about a person;
- use the project to target, shame, or punish people;
- submit malicious model artifacts, dependencies, or plugins;
- disclose private data or credentials.

Report unacceptable behavior to the maintainers through a private issue or repository security contact when available.
